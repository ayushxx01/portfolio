# 🍳 Meal Prepper

> A local-first AI meal planner built for real-life PG kitchens.

Meal Prepper helps you decide **what to cook with what you already have**.

Living in a PG often means having limited ingredients, limited cooking equipment, and very little motivation to figure out what to make. When deciding what to cook becomes a hassle, ordering food becomes the easier option.

Meal Prepper reduces that **decision fatigue** by generating meals based on available ingredients, cooking tools, and meal type — while also providing deterministic nutrition information.

---

## 💡 The Problem

When living in a PG, cooking often looks like:

```text
What ingredients do I have?
        ↓
What can I make with them?
        ↓
Do I have the equipment required?
        ↓
How much should I use?
        ↓
Fuck it, let's order.
```

This becomes even more important when trying to follow a diet or hit a daily protein goal.

Meal Prepper turns this into:

```text
Ingredients + Quantities + Tools + Meal Type
                    ↓
                  Gemma
                    ↓
              Feasible Recipe
                    ↓
             Nutrition Engine
                    ↓
             Recipe + Nutrition
```

## 🧠 How It Works

Meal Prepper separates **AI reasoning** from **deterministic application logic**.

### 1. User Input

The user provides:

```text
Ingredients:
- Rice: 200g
- Eggs: 3 pieces
- Onion: 1 piece

Meal:
Lunch

Tools:
- Pan
- Stove
- Knife
```

### 2. Local Gemma

The input is sent to a locally running Gemma model through Ollama.

Gemma determines a suitable recipe while considering:

- Available ingredients
- Available quantities
- Meal type
- Available cooking tools

Gemma returns a structured recipe containing ingredient quantities and cooking steps.

### 3. Recipe Validation

The application validates the generated recipe.

It checks that:

- Ingredients actually exist in the user's inventory
- The recipe doesn't use more than the available quantity
- Required cooking tools are available
- Unsupported or missing ingredients aren't silently introduced
- Cooking steps are compatible with the available equipment

Invalid recipes are rejected instead of being blindly shown to the user.

### 4. Unit Conversion

Nutrition data is stored primarily on a per-100g basis.

Ingredients already provided in grams can be used directly.

Supported piece-based ingredients can be converted using explicit application-level conversion data.

For example:

```text
1 egg ≈ 50g
1 onion ≈ 100g
```

These are approximate MVP conversions and are **not generated by the LLM**.

Unsupported conversions are rejected rather than guessed.

### 5. Nutrition Calculation

The application uses the local `nutrition.json` dataset to calculate:

- Calories
- Protein
- Carbohydrates
- Fat

For example:

```text
per-100g nutrition × ingredient weight / 100
```

The nutrition calculator is deterministic and does not rely on Gemma for nutritional arithmetic.

## 🚀 Running Locally

### Prerequisites

Install:

- Node.js
- Ollama
- The required Gemma model

Check Node:

```bash
node -v
```

Check Ollama:

```bash
ollama list
```

Make sure the required Gemma model is available locally.

### Start the application

From the project directory:

```bash
node server.js
```

The application runs at:

```text
http://127.0.0.1:3000
```

Open that address in your browser.

## 📴 Why Local AI?

The local-first architecture is intentional.

### Offline

PG Wi-Fi can be unreliable, and mobile networks can also become unavailable.

Because the core model runs locally through Ollama, Meal Prepper does not need an internet connection to generate meals once the required software/model is installed.

### Privacy

Ingredients, meals, and dietary information can stay on the user's machine rather than being sent to an external AI API.

### Free

There is no dependency on paid LLM API calls for the core meal-generation functionality.

## 📊 Nutrition Data

The project currently uses nutritional data based primarily on:

**Indian Food Composition Tables (IFCT) 2017**

Published by:

**ICMR — National Institute of Nutrition**

Nutrition values are stored on a per-100g edible-portion basis where applicable.

The application intentionally distinguishes between:

- Raw foods
- Boiled foods
- Dry foods
- Other preparation states

Missing nutritional values are treated as **unavailable**, not automatically as zero.

## 🤝 Project Philosophy

Meal Prepper is intentionally built around a simple principle:

> **Let the AI reason. Let deterministic code enforce the rules.**

Gemma handles the fuzzy problem of deciding what meal could be made.

The application handles things that should not be guessed:

- Available ingredients
- Quantities
- Equipment constraints
- Unit conversion
- Nutrition calculations

This keeps the system useful while avoiding unnecessary reliance on the LLM for things that normal software can handle more reliably.
